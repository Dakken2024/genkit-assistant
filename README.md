# GenKit Assistant 使用说明

> 本仓库**仅提供编译后的可执行文件（exe）与说明文档，不包含任何源代码**。  
> 软件版本：v1.0.0 Professional

---

## 一、项目简介

**GenKit Assistant** 是一款面向 **Geneious Prime 插件开发者**与**生物信息科研用户**的 Windows 桌面工具。它将"AI 自动化插件开发"与"轻量生信科研辅助"整合在一个开箱即用的本地程序中，无需搭建复杂的开发环境，下载解压即可使用。

所有处理均在**本机本地完成**，数据不出本机，兼顾易用性与隐私安全。

---

## 二、功能说明

- **AI 自动化插件开发闭环**：在程序内完成插件的需求梳理、规格生成、打包与验证，无需额外安装外部 IDE。
- **黑盒规格提取**：在隔离沙盒中运行目标程序并捕获其输入/输出，由 AI 归纳出可复用的规格说明。
- **Geneious 直接启动器**：一键启动 Geneious Prime 并注入所需插件参数，简化调试流程。
- **本地环境管理**：自动识别并管理 conda 环境与常用生信工具链，降低配置门槛。
- **生信知识库与百宝箱**：内置可检索的生信知识库，并集成轻量浏览器用于查阅在线资料。
- **本地优先、隐私友好**：核心任务均在本地运行，不上传用户数据与代码。

## 四、获取方式

本仓库不开放源代码，仅通过 **GitHub Releases** 提供已编译的可执行文件：

1. 进入本仓库的 **Releases** 页面（仓库顶部 `Releases` 或右侧"发行版"）。
2. 下载最新版本 `GenKit-Assistant-v1.0.0-windows-x86_64.zip`。
3. 将压缩包解压到任意目录，即可得到 `GenKit Assistant.exe`。

> 最新版下载地址：  
> `https://github.com/{{你的用户名}}/genkit-assistant/releases/latest`
>
> 建议下载后核对发布页提供的 SHA256 校验值，确保文件完整未被篡改。

## 五、使用步骤

1. **下载与解压**：从 Releases 下载压缩包，解压到任意目录（建议路径**不含中文与空格**）。
2. **首次运行**：双击 `GenKit Assistant.exe`。若系统弹出"Windows 已保护你的电脑"提示，点击"更多信息"→"仍要运行"（属正常误报，本程序不含恶意代码）。
3. **基础操作**：
   - 启动后进入主界面，可在左侧选择"插件开发"或"生信百宝箱"等功能模块。
   - 以插件开发为例：在对话框中描述需求 → 程序自动生成规格与代码 → 点击"打包"生成插件包 → 通过"直接启动器"在 Geneious 中验证。
   - 结果文件默认保存在程序所在目录的 `data/` 文件夹中。
4. **退出**：点击右上角关闭按钮，程序将自动保存当前状态。

> 更详细的操作指引，请参阅同仓库中的 `使用手册.md`。

## 七、常见问题（FAQ）

**Q：杀毒软件提示风险 / 无法启动？**  
A：多数情况是误报。请将本程序所在目录加入杀毒软件白名单，或按"使用步骤-首次运行"中的方式放行。

**Q：提示缺少 WebView2 或某个 .dll？**  
A：请安装最新版 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)；Windows 10/11 通常已自带。

**Q：我的数据会被上传吗？**  
A：不会。核心处理均在本地完成，不上传任何用户数据、代码或文件；仅在使用 AI 与在线资料功能时产生必要的网络请求。

**Q：可以获取源代码吗？**  
A：本仓库仅发布编译后的可执行文件，**不公开源代码**。

**Q：支持 macOS 或 Linux 吗？**  
A：当前仅提供 Windows 版本，暂无其他平台计划。
